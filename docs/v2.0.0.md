# AgentPort 2.0.0

AgentPort 2.0 replaces the multi-step TextGen-first experience with one recommended local agent flow.

## Highlights

- Qwen3-Coder 30B-A3B at 49,152-token context is the verified 16 GB default.
- AgentPort automatically installs the runtime and model, configures Harness and selects the matching model.
- ComfyUI, Blender and generic MCP connections have a single guided manager.
- Home shows live VRAM, RAM and token statistics, plus dependable stop and restart controls.
- Existing GGUF files are discovered but labelled unverified.
- NInfer and legacy controls remain available under Advanced.

## Validation

- Real ComfyUI workflow creation, validation and execution passed.
- Real Blender 5.2 scene modification and independent verification passed.
- The combined agent test completed without repeated continue prompts.
- Weighted generation speed was approximately 104 tokens/second on the RTX 4080 16 GB test system.
- Packaged start, stop, restart and cleanup passed.

Tested on Windows with an NVIDIA RTX 4080 16 GB and 64 GB system RAM. RTX 30/40 compatibility is supported by the setup flow, but performance and available context vary by system.
