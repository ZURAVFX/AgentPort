# AgentPort 3.1.31

Fixes AgentPort rejecting Codex interruption messages with “Responses WebSocket messages must have type response.create.” while steering or stopping a running reply. Interruption controls now bypass the generation queue, validate the response they target, stop the internal request and preserve completed output items for the next turn. Unfinished items are discarded and follow-up input is sent once. Usage is never invented as zero for a cancelled generation.

Install update now queues the verified installer when model requests, downloads or sign-in are active. A neutral Update queued message explains the wait and offers Cancel update. Router health is checked before and after checksum verification. Unavailable status remains a wait; genuine installation failures remain retryable. Queue state survives page navigation but is not saved across quitting AgentPort.

On Apple Silicon, the queued action opens the DMG; replace AgentPort in Applications to finish. Older versions keep the old busy-update behaviour until updated once. Finish active requests for that first installation. Updating the desktop app can leave the previous background router running. After installing this release, finish active chats and restart the computer to activate the new router.

Verification: 85 routing, WebSocket, update, account, heartbeat and Haiku regression tests; 107 desktop tests, with six platform/environment skips; final update UI test; syntax and TypeScript checks. Tests used local provider fixtures, with no paid inference.

Native model context, credentials, account choices and model visibility settings are unchanged. The existing Haiku size safeguard remains; this update does not claim to resolve all Haiku context inflation. Source remains in the private development repository.

The Windows x64 installer is provided. Apple Silicon remains on 3.1.30 while its native build is pending; the Mac fixes are in the private source tag but are not yet packaged or active. The Mac preview supports API models only and is ad hoc signed, not notarised.
