Web2AE setup

Browser → editable After Effects layers. Everything stays on your machine.

1Install the After Effects companion

Download Web2AE Companion for Windows from the same GitHub/Gumroad release where you found Web2AE. Extract it and run Install Web2AE.bat.

2Open Web2AE in After Effects

Restart After Effects, then choose Window → Extensions → Web2AE. Leave the panel open while capturing.

3Capture any normal webpage

Return to the page you want, open the Web2AE browser extension and click Send Current Page to AE. Chrome may request one-time high-fidelity page inspection permission.

Web2AE does not upload page data to a cloud service. The browser extension sends the current page only to the local Web2AE bridge at 127.0.0.1.
