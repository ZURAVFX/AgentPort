# AgentPort 3.1.32

- Context Manager starts with **Global Codex routing account**. Choose the subscription for chats following the global default, or add, sign into and remove saved accounts in the same card. Changes apply to new messages; running replies and per-chat overrides keep their account. The desktop login is not replaced by this selector.
- Settings and Usage link to Context Manager rather than duplicating account controls. Usage keeps each account's allowance readings.
- **Settings → Background service → Run at startup** controls the desktop app's own login entry, separately from the router service policy. It does not change your preference until you use the switch. Failed writes show an error rather than claiming success.

Token maxxing was checked with 24 focused tests and a local fixture that reduced an eligible old tool output from 120 KB to about 2.5 KB while preserving recent output. It does not increase context limits, and reductions are not measured billing savings. Rewriting can affect prompt caching. Native GPT processing remains separately opt-in; no settings were automatically enabled.

Verification: 109 desktop tests passed with six environment/platform skips, plus four startup preference tests and 24 output-reduction tests. Syntax and TypeScript checks passed. No paid inference or real login-on-reboot test was performed.

The Windows x64 installer is provided. Apple Silicon stays on 3.1.30 while native packaging is pending. After installation, finish active chats and restart your computer to ensure the matching background router is loaded. Source remains in the private development repository.
