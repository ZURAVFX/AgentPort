# AgentPort 3.1.44

Context Manager now offers a **Max** preset for native GPT models. It uses the model's supported context window and starts compaction at 90% of the space Codex makes available.

For GPT-6.2 Astra and Sol with an 872,000-token window, compaction starts at 745,560 tokens. That leaves 82,840 usable tokens for replies and tool results.

To apply it, open **Context Manager → GPT context windows**, expand a model, choose **Max** and save. Fully quit and reopen Codex, then start a new chat. You can set each model independently or restore its Codex default.

Available for Windows x64 and Apple Silicon. The Mac preview is ad hoc signed and has no Apple notarisation.
