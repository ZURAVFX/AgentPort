# AgentPort 3.1.43

Keeps the native GPT model catalogue refreshed automatically at service start
and every five minutes, including when the desktop app and CLI update separately.

- An older resolved CLI no longer freezes discovery. AgentPort uses the newest
  Codex version already observed locally in the current catalogue or executable.
- First launch can use a successful account-bound discovery even when Codex has
  not written its own model cache yet.
- New models are discovered from the signed-in account, with no model-name list
  to update manually. Account access and Codex compatibility still apply.
- Codex's own cache, existing native metadata and saved context settings remain
  unchanged. Discovery from another account or native snapshot is not reused.
- Added a regression that discovers an arbitrary future model and publishes it
  through the background drift path without changing Codex's own cache.

**If GPT-6.2-Sol or GPT-6.2-Astra is already in AgentPort's catalogue but missing
from the Codex picker, fully quit and reopen Codex, then start a new chat.**
AgentPort refreshes its catalogue automatically; a running Codex app can retain
the model list it loaded at launch.

Windows x64 and Apple Silicon installers contain the matching interface and
router. Mac packages are ad hoc signed and are not notarised.
Source development remains private. Public assets contain installers and checksums.
