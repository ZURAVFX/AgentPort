# AgentPort 2.0.7

- Experimental-family buttons now expand and scroll to the Hugging Face installer instead of updating a hidden section.
- Repository inspection separates model GGUFs from optional `mmproj` helpers.
- Users explicitly choose a model quant and either an available helper or the clear text-only option.
- AgentPort downloads the selected model and helper together and records their association.
- Repositories without helpers state that clearly instead of silently omitting the choice.
