# AgentPort 3.1.33

Clarifies two optional settings without changing their underlying behaviour or your configuration:

- **Alternative Codex routing (advanced)** replaces Use Router with ChatGPT and is collapsed by default. It is a compatibility mode, not the main AgentPort switch. Standard routing can already work with it off. Leave it unchanged if your models work. Changing it modifies the Codex provider configuration and requires reopening Codex.
- **Allow ChatGPT in other local apps** replaces Share ChatGPT subscription. It allows other local clients to spend your ChatGPT allowance. It is not needed for Codex itself or choosing saved accounts. Existing sharing consent remains required.

These English labels were clarified; existing translations remain in place. No settings, credentials, model visibility or native GPT context limits are automatically changed. Compatibility routing remains available rather than being removed.
