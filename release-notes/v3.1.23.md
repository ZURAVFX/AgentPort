# AgentPort 3.1.23

## Add Codex accounts in one place

**Codex Accounts** is now a visible item in the left sidebar. Click **Add Codex account**, complete sign-in in your browser, and repeat for each ChatGPT subscription you own. An optional name such as Personal or Work makes accounts easier to recognise.

Choose **Choose account for a chat** to open Context Manager. Select an account on an existing Codex conversation and click **Apply**. Different conversations can use different accounts at the same time, without creating separate Codex windows.

A running task keeps its account. Changes apply at a confirmed new Codex turn, including after tool calls or a router restart. The existing conversation and its Open app/Resume session identity are preserved.

## Clearer setup and recovery

- Duplicate additions are blocked while sign-in is starting.
- If the browser cannot open, the saved account stays in the list. Use **Sign in** on that row to retry.
- **Use for app** is separate: it changes the main Codex desktop login after Codex closes. Per-chat choices stay in Context Manager.
- Existing API provider routes keep their own credentials.
- The release source retains executable permissions for its Mac/Linux launchers.

## Install the update

After active tasks finish, fully quit AgentPort and Codex. Run the Windows installer over your current installation, or replace AgentPort in Applications using the Apple Silicon DMG. Reopen AgentPort and Codex.

Then open **Codex Accounts → Add Codex account**. No Git checkout, terminal build or separate account-manager installation is required.

The installer contains matching versions of the interface and router. Release checks verify account-routing behaviour, the production interface, platform packages and installer checksums.

## Compatibility notes

Cross-account acceptance of existing account-scoped reasoning, compaction state and uploaded files has not been tested against real accounts. The new account must also support the chosen model. Backend refusals remain visible rather than deleting context or silently using another account. Multiple accounts do not make a single response faster.

The Mac package is an **Apple Silicon preview**. It is ad hoc signed, not Apple-notarised, and retains the existing API-only scope. Local inference is not included. See the [Mac installation notes](v3.1.22.md) for the existing installation guidance.

Application source and development history remain private. This public repository distributes installers, checksums, release notes and the download page only.
