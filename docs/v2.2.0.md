# AgentPort 2.2.0

This update focuses on reliable controls and a simpler everyday workflow.

- Harness stopping recognises the AgentPort-managed server even when it uses system Node or its original launcher has exited. Process ownership is checked before stopping it.
- Model discovery and regular status checks run in the background. Model visibility changes reuse the discovered list instead of rescanning the disk.
- Models has **Show all** and **Untick all** for discovered models. These only change what appears on Home; model files stay on disk. The managed recommended option remains available.
- Home keeps Start, Open agent and separate stop controls together. Resources remain visible, with the activity log available when expanded.
- Advanced model imports and downloads follow the model list. Settings groups maintenance and removal actions.
- Qwen3-Coder 30B-A3B IQ3_XXS at 48k remains the previously tested RTX 4080 recommendation. Other discovered files are not automatically endorsed because of their filename.

The recommendation refers to the earlier RTX 4080 16 GB creative-tool tests, not a new benchmark or a guarantee for every NVIDIA GPU. The upstream [Qwen model card](https://huggingface.co/Qwen/Qwen3-Coder-30B-A3B-Instruct) documents its tool-calling support.

## Verification

Verified on Windows with an RTX 4080 16 GB:

- Stopped the existing Harness server and confirmed 69 checked Adobe/Codex process identities were unaffected.
- Stopped an orphan Harness fixture while an independent backend remained running.
- Checked unrelated listeners and reused process IDs are preserved.
- Confirmed the WPF dispatcher continues ticking during a slow background operation and timeout cancellation returns promptly.
- Exercised both bulk buttons with isolated settings, checking persistence and unchanged model-file hashes.
- Parsed the PowerShell source and ran the packaged EXE smoke test, including Home at the minimum window size, Models and Settings.

Harness install/update waits remain bounded waits that process UI events; routine scanning, status collection and Home stop operations run in background workers. This update does not claim a new inference benchmark or comprehensive fresh-PC hardware coverage.
