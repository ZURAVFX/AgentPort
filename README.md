# Public Tools

A collection of free public tools by Elliot / ZURA VFX.

## AgentPort

AgentPort connects **local GGUF AI models** to **DeepSeek Harness** on Windows.

It is built for people who want to run local models through TextGen and use them inside a Harness-style agent workflow without juggling multiple launch scripts, model folders and config files.

- [AgentPort guide](./AgentPort/README.md)
- Download: `AgentPort_v1.5.0.exe` from `AgentPort/releases/` once the binary is uploaded
