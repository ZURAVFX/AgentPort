# AgentPort 2.0.6

- Writes AgentPort's AppUserModelID directly to the native WPF window property store.
- Sends the AgentPort small and large icons directly to the window using `WM_SETICON`.
- Avoids Windows inheriting the PowerShell host icon for the visible taskbar window.

This complements the process identity, registered relaunch information and embedded executable icon added previously.
