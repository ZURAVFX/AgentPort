# AgentPort 2.0.3

This release completes the simplified local model workflow.

- Existing GGUFs run through AgentPort's managed CUDA llama.cpp backend. TextGen is not required.
- Detected-model checkboxes now control which models appear on Home.
- Permanent model deletion remains a separate confirmed action.
- Local GGUF import has a dedicated advanced section with optional `mmproj` helper selection.
- A helper can be added or changed for an already detected model.
- Automatic helper matching avoids attaching a projector from an unrelated model family.
- Completed runtime notifications fade out after a short reading period.
- Sidebar navigation is consistently aligned.
- The current model is passed automatically to DeepSeek Harness.
- ComfyUI, Blender and general MCP setup remain available from Skills & MCPs.

The packaged EXE passed PowerShell parsing, UI rendering and packaging checks on Windows 11 with an NVIDIA RTX 4080 16 GB.
