# AgentPort 2.0.8

The Models page is simpler and safer:

- Redesigned Home visibility checkboxes.
- **Remove** forgets a model in AgentPort without deleting its GGUF file.
- Scanning shows clear busy, success, empty and failure states.
- Removed the redundant experimental-family shortcuts.
- Long model names are truncated with the full path available as a tooltip.
