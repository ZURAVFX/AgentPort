# AgentPort 3.1.24

## Fix account sign-in with Codex Desktop

The Codex Accounts page could report **Codex CLI is not installed** when the desktop app was installed but no separate CLI was on PATH. This was an AgentPort detection bug.

Account sign-in now uses the shared desktop-aware Codex detector. It can use the helper already bundled with the desktop app rather than requiring a separate global CLI installation. The detector also recognises the newer ChatGPT Mac app's nested `codex-cli` layout alongside the older Codex app layout and Windows version-hashed installations.

When no helper is available, the message points to installing or updating the desktop app instead of presenting a CLI-only error. The existing per-account home, browser sign-in, process ownership, retry and finalisation safeguards are unchanged. Adding an account does not replace your main desktop login.

## Update and retry

Finish active tasks and quit AgentPort. Install this update over your existing copy, then reopen AgentPort. In **Codex Accounts**, click **Sign in** beside the account you already added. There is no need to remove it or create it again. Complete sign-in in your browser, then choose the account for a conversation in Context Manager.

You can continue using the Codex desktop app. No manual terminal login, global CLI install or API key is required for this setup path when a supported desktop helper is present.

## Verification and limits

Regression coverage includes desktop-only detection, current and legacy Mac layouts, Windows version-hashed helper selection, packaged-helper lookup, missing-helper recovery instructions and browser handoff into an isolated account home. Release verification checks the packaged IPC and resolver against the tested source.

Real account authentication still requires you to complete browser sign-in. Automated tests do not claim a successful live cross-account conversation or acceptance of account-scoped reasoning and uploaded files.

The Apple Silicon build remains an ad hoc-signed preview, not Apple-notarised, with the same API-only scope. Local inference is not included in the Mac preview.
