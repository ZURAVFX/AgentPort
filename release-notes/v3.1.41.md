# AgentPort 3.1.41

AgentPort's desktop interface has a shared visual system with clearer controls,
more readable text and less clutter across Local, API Models, Usage and Settings.

- Added the tested Qwen3.8-27B GSQ3 native NInfer profile to Local, with detection
  of existing WSL files, context settings, Start and Stop & unload. Fresh native
  NInfer installations still require the runtime and model files shown in Setup.
- Kept Flash Next with Strata alongside other local models. Start uses MTP,
  quantised KV and a GPU-memory reserve. Port selection avoids conflicting apps.
- Stop can cancel Strata startup. Unloaded models no longer retain stale live
  telemetry or an active restart warning.
- Local model paths are available in expandable File location details. The
  download browser filters out explicitly unsupported audio and music models.
- API Models separates local runtimes and hides empty provider groups. Existing
  provider credentials, visibility choices and native GPT defaults are retained.
- Page navigation returns to the top, usage summaries wrap at narrow widths,
  keyboard focus is clearer, and Settings no longer offers Start while online.
- Removed Claude Haiku routes and blocked stale Haiku requests locally.
- Included the opt-in local Code Mode and tool-surface fixes exercised in the
  local inference comparison. These apply to the explicit local routes.

Windows x64 and Apple Silicon installers include the matching interface and router.
macOS packages are ad hoc signed and are not notarised.

Source development remains private. Public assets contain installers and checksums.
