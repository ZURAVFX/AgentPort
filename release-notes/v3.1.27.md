# AgentPort 3.1.27

Adds guided OpenRouter setup to API Models. Create a key from the direct link, save it securely through AgentPort, browse the current OpenRouter model catalogue, and choose models for Codex. The setup explains OpenRouter billing and the Codex restart needed to refresh its model picker.

Free routes remain subject to OpenRouter limits. Paid models use OpenRouter credits and account controls.

Windows x64 installer. Apple Silicon remains on 3.1.24.
