# AgentPort 3.1.25

Choose **Use this subscription** in Codex Accounts to send new native Codex turns through a saved ChatGPT subscription. You can use two signed-in accounts in one Codex instance. Each keeps its own allowance; this does not merge or increase either account's limits. Existing turns, retries and subagents keep their bound account. Explicit per-chat selections in Context Manager still take precedence. Choose **Codex app login (default)** to return to the desktop's own account.

Successful browser sign-in no longer reports a false failure when status recovery finishes before the desktop callback. Overlapping account sign-ins are blocked with a clear explanation. A saved login that becomes usable also clears its stale error notice.

The app checks GitHub for a newer stable release on launch and downloads the matching installer automatically. Published size and SHA-256 must match before installation is offered. Windows installs from the **Install update** button after active work has finished. On Apple Silicon, this opens the verified DMG for the normal drag-to-Applications installation. The Mac build remains an ad hoc-signed preview, not Apple-notarised.

Provider catalogue discovery already refreshes on every launch, including connected OpenCode Go/Zen sources and enabled free routes. Regression checks confirm a fresh launch bypasses the cache, offline use retains the saved list, and existing model choices are preserved. New models are available to choose in API Models; publication into Codex still requires its picker to refresh.

This release does not change native GPT context-window settings or API-provider credentials. Install the matching router and desktop update before using the subscription selector; an older running router is detected rather than silently ignoring the selection.

Verification includes two distinct saved subscriptions each returning a completed live response through AgentPort, account-routing regression tests, sign-in recovery checks, renderer interaction tests, and updater checksum/rejection tests. Automatic installation of a future release cannot be verified until a newer compatible release exists.

Delivery: Windows x64 is available. Apple Silicon remains on 3.1.24 because GitHub build jobs are blocked by account billing and the connected Mac did not respond. No 3.1.25 Mac installer has been published.
