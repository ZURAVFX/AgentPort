# AgentPort 2.3.3

Fixes **Open Harness** failing with `System.Int32 does not contain a method named 'Contains'` on Windows PowerShell 5.1.

- Corrects context selection for both an active model and a saved context preset.
- Keeps the model loaded when opening Harness independently.
- Supports an explicit `harness_base_url` launch setting for compatibility with Harness versions that require provider routing in the launching environment. Project `.env` files are not automatically imported into that trusted environment.
- Adds regression coverage using the production Home buttons and context presets under Windows PowerShell 5.1.

Download **AgentPort.exe** below. Close the old AgentPort window before opening the new version. Models and settings are preserved.
