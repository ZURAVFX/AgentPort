# AgentPort 3.1.20

Claude Haiku 5.5 on OpenCode Go now uses Codex Code Mode. A fresh chat can
discover and execute connector tools when needed, instead of sending the full
installed tool catalogue upfront. This fixes the excessive prompt overhead
observed with large connector inventories.

Freeform JavaScript exec calls are bridged into the Messages API and restored
to native Codex calls. Clients that do not supply Code Mode keep their existing
tool handling. Native GPT models and their context settings are unchanged.

Restart Codex after updating, then start a new Haiku chat to use the new tool
mode. An existing chat's previous token meter is not retroactively recalculated.

The application source remains in the private development repository. Public
downloads contain the Windows installer and its SHA-256 checksum.
