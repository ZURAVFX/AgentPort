# AgentPort 3.1.42

Fixed the Dashboard speed comparison being squeezed into a narrow card with
missing model names and unused space beside it.

- The speed section now fills the available width, with larger labels and
  wrapping model names.
- Narrow windows show each model above its latest speed, average speed and
  measured-reply count. All metrics remain visible without sideways scrolling.
- Shared page sizing prevents wide content expanding beyond the visible page.
- Hidden Usage chart tooltips no longer create invisible horizontal overflow.
- Added layout regressions across all seven navigation pages, light and dark
  themes, and three desktop window widths.

Model routing, credentials and context settings are unchanged.
Windows x64 and Apple Silicon packages contain the matching interface and router.
Mac packages are ad hoc signed and are not notarised.

Source development remains private. Public assets contain installers and checksums.
