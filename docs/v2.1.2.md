# AgentPort 2.1.2

## Harness startup repair

- Automatically removes duplicate `agent-presets.default` keys from the DeepSeek Harness settings file before startup.
- Keeps a one-time backup beside the repaired file so existing user settings remain recoverable.
- Applies the same repair when installing the low-thinking or team presets.

## Clearer local backend status

- Managed GGUF startup messages now identify the local GGUF backend instead of calling it TextGen.
- The legacy TextGen integration remains available as an optional fallback for installations that still use it.
