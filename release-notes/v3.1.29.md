# AgentPort 3.1.29

Fixes the clipped update banner. Update progress, the ready message and Install update control now appear below the title bar in the scrollable page content. Status and error messages take their natural height instead of occupying the fixed-height navigation row.

Verified downloading, ready, installer rejection, navigation and no-update states, including desktop and narrow window layouts. Model selections, credentials, routing and context settings are unchanged.

Usage now lists every saved Codex subscription with its own reported allowance windows and reset times. Account management and performance/request details are expandable sections in Usage, replacing two sidebar tabs. Unavailable readings remain explicit; account allowances are never added together.

Windows x64 release. Apple Silicon remains on 3.1.24.
