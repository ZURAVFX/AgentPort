# AgentPort 2.3.2

This rebuild addresses launch robustness and usability regressions from the previous release, including startup edge cases when no active model is selected.

## Key changes

- **Fixes**: Harness can start from Home without requiring a pre-populated `active_model`.
- **Model lifecycle**: fallback-safe context/model selection and safer startup paths so users can keep model and harness flows aligned.
- **Packaging**: includes fresh `2.3.2` runtime and exe binaries for deployment.

## Validation

- Local rebuild of launcher and embed bundle completed.
- Runtime startup smoke tests pass with updated Home/startup flow.
