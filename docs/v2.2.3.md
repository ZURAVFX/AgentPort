# AgentPort 2.2.3

AgentPort-managed Harness presets now disable Harness' default and project skill roots. Only the explicit `%USERPROFILE%\.dsh\harness_skills` folder is mounted, so skills installed for Codex or other agent tools (such as Impeccable) are not exposed to DeepSeek Harness.

Existing managed presets are backed up once as `agent.cordis.yml.before-skill-isolation` before being updated. User-created presets are not modified.
