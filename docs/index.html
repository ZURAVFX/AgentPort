From install to first request.

AgentPort runs locally and publishes the model choices you enable into Codex.

  1. Install AgentPort

    Run the Windows installer, or open the Apple Silicon DMG and drag AgentPort into Applications.

  2. Connect and choose models

    Open AgentPort, set up Codex, connect the providers you use, and enable the models you want.

  3. Choose the model in Codex

    Select the published model in Codex. Restart Codex after changing its model list to refresh the picker.

Install AgentPort.

Choose the Windows installer or Apple Silicon Mac preview. The Mac preview supports Codex and API providers, including OpenCode, with no Homebrew setup required.

  1. Download the installer

    On Windows, run the .exe. On an Apple Silicon Mac, open the DMG and drag AgentPort into Applications.

  2. Open the Control Center

    Follow the Codex setup in AgentPort and connect only the providers you intend to use.

  3. Refresh Codex

    After adding or changing models, restart Codex so the model picker reloads.
