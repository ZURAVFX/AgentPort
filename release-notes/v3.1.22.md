# AgentPort 3.1.22 Apple Silicon preview

Connecting or enabling a provider now prompts you to choose models. The API
Models page explains that connecting an account does not automatically show
every model, and that Codex needs a full quit and reopen after model selections
change. Existing visible and hidden model choices are preserved.

API Models now groups models with a free provider route together in a clearly
labelled Free models section. Paid and subscription models appear separately.
Disconnected free routes stay in the free group and explain that a provider
connection is needed. For models with several routes, expand the model to
choose its free provider. Provider usage limits can still apply.

The source is maintained privately in
`OA-Motion/project_development_files/AgentPort`. The public AgentPort repository
contains release downloads and product documentation only.

## Verification and remaining limitations

- On the M5 Mac, a fresh Codex app-server returned all 41 selected OpenCode models,
  including Claude Haiku 5.5 and DeepSeek V4.1 Flash.
- A real DeepSeek Flash request reached OpenCode, which returned HTTP 429:
  Go usage limit exceeded. Successful inference remains unverified on that account.
- The installed 3.1.21 app passed signature integrity verification but was
  rejected by Gatekeeper. This update does not change the signing identity.
  The Mac app remains ad hoc signed and is not notarised. Open Anyway alone
  did not resolve the reported launch failure. See `docs/MACOS-DESKTOP.md` in
  the private source for the investigation and reported workaround.
- Local models remain outside the Mac preview's scope.
