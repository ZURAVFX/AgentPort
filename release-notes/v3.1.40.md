# AgentPort 3.1.40

Choose a separate context window for each native GPT model in Context Manager. Use the Codex default, the 1-million-token preset with compaction at 900,000 tokens, or custom limits within that model's supported capacity. Restore a model's default independently at any time.

Context changes are opt-in. Local models and third-party API models keep their own settings. Fully quit and reopen Codex, then start a new chat after saving a GPT context change. Larger budgets can increase latency and usage; they are not automatically better for every task.

This release also includes the pending 3.1.39 account sign-in improvements: visible, copyable device codes, explicit retry and cancel controls, and continued access to ready accounts while another account signs in.

NVIDIA NIM requests now omit unsupported Codex parameters and avoid resending oversized tool catalogues. A real NIM response was verified inside Codex, although provider response times can still be slow.

Downloads: Windows x64 installer and Apple Silicon macOS DMG/ZIP. macOS builds are ad hoc signed, not notarised. Checksums are included. Source development files remain in the private OA-Motion repository.
