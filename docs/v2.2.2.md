# AgentPort 2.2.2

## Auto-continue cut-off replies

On **Home > Agent controls**, enable **Auto-continue cut-off replies** and choose the maximum number of automatic continuations per request. New installations default to off, with a limit of 10. Available limits are 5, 10, 20 and 50.

When Harness reports an output-token limit, AgentPort waits briefly and sends a clearly labelled continuation message. It asks the model to resume the existing request without repeating finished work or broadening the task. Each automatic message shows its count and limit.

- Normal completion does not trigger another turn.
- Stop cancels a pending continuation, including between replies.
- Backend errors, permission requests and context failures are not automatically retried or approved.
- Switching the option off prevents further continuations; use Stop in Harness to cancel a reply already running.
- The limit resets for a new human request. Turning the option on does not replay old cut-off conversations.
- Changes apply immediately to Harness launched by this version. Restart an older Harness instance once after upgrading.

This removes the need to type `continue` for output-limit stops, not every reason an agent may pause. It does not guarantee task completion, grant extra permissions or allow unlimited unattended execution. Automatic continuations consume additional model tokens and may perform further tool actions within the original request.

The integration is a local plugin loaded by AgentPort, not an edit to the installed Harness package. Local options are stored in `%LOCALAPPDATA%\AgentPort\auto-continue.json`.

## Verification

Tested against the installed real Harness with an isolated home directory and deterministic OpenAI-compatible streaming test backend: disabled mode, length-limit continuation, normal completion, continuation cap, Stop during the pending delay, switching off during the delay, and backend errors. No real model throughput claim is implied by these control-flow tests.

Windows PowerShell persistence checks and the packaged UI smoke test also passed. The minimum-size Home layout keeps the setting with the existing agent controls.
