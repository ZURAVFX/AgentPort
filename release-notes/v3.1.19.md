# AgentPort 3.1.19

Claude Haiku 5.5 through OpenCode Go now works with Codex requests. AgentPort
removes Codex's `access_programs` routing hint before forwarding to Anthropic's
strict Messages API, which had rejected the extra field with HTTP 400.

This compatibility change is scoped to Anthropic Messages providers. Native
OpenAI model requests remain unchanged. The regression tests cover both the
OpenCode Go Haiku route and the full local router-to-Anthropic forwarding path.
