# AgentPort v1.6 setup and discovery

This documents the v1.6 setup/discovery feature set, as shipped in the current
**v1.6.2** build. v1.6 makes AgentPort clearer for first-time users and more
useful for people who already have models installed in other local AI tools.

## Setup checks

The Settings page now shows separate status flags for:

- TextGen
- DeepSeek Harness

Each can report:

- Installed
- Missing
- Needs repair

The user also gets explicit install/repair buttons instead of having to infer setup from the main launch button.

## TextGen setup

AgentPort downloads the TextGen source, patches the interactive `pause` in `start_windows.bat`, and runs the first-run installer hidden with a visible progress phase in AgentPort.

TextGen launches through its isolated Python environment with:

- local API enabled
- port `5100`
- API key `local-textgen`
- selected GGUF model
- selected context length
- selected KV cache
- selected GPU offload mode

## DeepSeek Harness setup

AgentPort prepares a portable Node/npx runtime and warms the `@deepseek-ai/dsh` package cache. Harness launches with the local TextGen provider environment variables set.

## Model discovery

The model scanner checks AgentPort/TextGen defaults plus common model locations used by Ollama, LM Studio, Unsloth Studio, Hugging Face, Jan and GPT4All.

External GGUF files can be launched in place. If a nearby `mmproj*.gguf` helper file exists, AgentPort adds it to the TextGen launch flags. When you import a model whose helper isn't adjacent, AgentPort offers to pick the `mmproj` file directly during import.

## Skills page

The Skills page now has action buttons:

- Add skill folder
- Import skill ZIP
- Create blank skill
- Open skills folder
- Refresh

Skills stay isolated in `%USERPROFILE%\.dsh\harness_skills` and are copied into DeepSeek Harness at launch.

## Fixed across v1.6

v1.6.0 / v1.6.1:

- TextGen and DeepSeek Harness install status detection and repair buttons
- model scanner across common local AI tools
- `mmproj` helper discovery beside GGUF files
- clearer Skills import/create flow
- launch phase text encoding issue

v1.6.2 (current):

- **Startup crash fixed** — the model scanner passed a comma-separated list to
  `Join-Path`, so it threw before the window opened. This is why v1.6.0/v1.6.1
  appeared to do nothing on a real PC.
- **Home page fits without scrolling** — spacing tightened; the window is clamped
  and centred to the screen work area.
- **Helper (`mmproj`) import** — importing a GGUF now offers to attach the projector
  helper file when it isn't beside the model.
- Correct version label in the app footer.

## Gumroad update copy

AgentPort connects local GGUF AI models to DeepSeek Harness on Windows. v1.6.2 fixes the startup failure that made earlier builds appear to do nothing, keeps the whole Home page on screen without scrolling, and adds a clear way to import a model's `mmproj` helper file — on top of the v1.6 install-status flags, one-click TextGen/Harness install buttons, smarter model discovery and a simpler Skills page.
