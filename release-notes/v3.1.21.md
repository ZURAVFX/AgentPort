# AgentPort 3.1.21: Apple Silicon preview

This release adds a standalone Mac installer for Apple Silicon, including M5.
It focuses on Codex and API providers such as OpenCode Go/Zen. Local model
downloads and inference are not included in this Mac release. Native GPT model
metadata, context settings and ChatGPT authentication are unchanged.

## Install on your Mac

1. Download `agentport-3.1.21-macos-arm64.dmg`, open it and drag AgentPort to Applications.
2. Open AgentPort from Applications. This preview is ad-hoc signed, rather than
   Apple-notarised. If macOS blocks it, use System Settings > Privacy & Security >
   Open Anyway after attempting to open the app. Do not disable Gatekeeper.
3. In API Models, connect your OpenCode account/key or another provider and select models.
4. In Harness, turn on Codex. The first connection installs the pinned Python
   gateway dependencies automatically. Internet access is required; allow several
   minutes for this step. Node and uv are already bundled, so Homebrew is unnecessary.
5. Fully quit and reopen Codex, start a new chat and select the routed model.

The router runs as your user's launchd service after setup. AgentPort has its own
menu-bar icon; it does not install the older separate Swift companion. To update,
quit AgentPort and replace the app in Applications with the newer Mac installer.
The owned router checkout is refreshed while saved settings and environments stay
in place. Router files live in `~/.local/share/agentport`, bundled tools in
`~/.local/share/agentport-runtime`, and state in `~/.codex/agentport`.

The stable Windows release remains 3.1.20. This Mac build is published as a preview
until installation and real provider requests are confirmed on a user's Mac.

## Verification

The Mac build pipeline verifies the ad-hoc app signature, arm64 runtime execution,
npm links, provider discovery, launchd rendering and a simulated owned-checkout
upgrade. These package checks do not replace a live Codex/provider test on the M5.
