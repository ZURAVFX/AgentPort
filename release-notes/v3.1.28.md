# AgentPort 3.1.28

API Models now shows only connected providers, grouped into collapsible lists. Search across those providers, filter to models in Codex or free models, and reveal more rows as needed. The separate Add models dialog is gone: switch on a catalogue model directly in its provider list. Existing model visibility choices are preserved.

Adds guided NVIDIA NIM setup in API Models. Open NVIDIA Build to create a key, enter it securely in AgentPort, browse the live NVIDIA catalogue and choose models for Codex. These models run on NVIDIA infrastructure. No local model download or local GPU is required.

NVIDIA provides free developer access for prototyping subject to its account limits and model availability. Models listed by the catalogue are not automatically verified for Codex tool use. Embedding, reranking, reward and document-parsing services are excluded from the chat list.

Connecting preserves model visibility choices. Select the models you want, then fully quit and reopen Codex to refresh its picker.

The OpenRouter setup flow remains available. Native GPT model settings are unchanged. Discovery and setup were checked with offline fixtures and the public NVIDIA catalogue; no authenticated inference request was sent.

Windows x64 release. Apple Silicon remains on 3.1.24.
