# AgentPort 2.0.1

This update makes runtime state and stop actions explicit.

- Separate **Stop backend** and **Stop Harness** controls on Home
- A combined **Stop all & free VRAM** action
- Immediate busy state followed by a clear success or error result
- Clear explanation of what remains running after each action
- Reported GPU layer placement shown when the backend exposes it
- Clear explanation of GGUF memory mapping and system RAM use
- Maximum safe GPU offload remains the default

The packaged EXE passed the Windows launch and interface render check on the verified RTX 4080 16 GB system.
